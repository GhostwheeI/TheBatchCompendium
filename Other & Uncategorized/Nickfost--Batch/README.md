# Batch Scripts Collection

A collection of batch scripts for various Windows automation tasks.

## ⚠️ Warning

Some of these files can cause undesired results... I'm not liable for them, use at your own risk!

## Original Repository

This collection is from [Nickfost/Batch](https://github.com/Nickfost/Batch)

## Contents

This directory contains various batch scripts including:
- Calculator.bat
- Clean free space.bat
- Commander utilities
- Counter scripts
- Exponential Multiplication.bat
- Info Finder.bat
- RACA.BAT
- Resilio Sync Backup.cmd
- Window Test utilities
- And more...

## Usage

Run batch files as administrator when required. Review each script before execution to understand its functionality and potential impact on your system.
