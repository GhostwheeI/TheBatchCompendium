# Scripting Libraries, Examples & Tutorials

This folder contains comprehensive batch scripting libraries, educational examples, and tutorials for learning and reference.

## Included Repositories:
- **happy05dz--Batch-Script-Collection** — Collection of various batch script examples and utilities
- **npocmaka--batch.scripts** — Extensive library of batch script utilities, functions, and examples covering string manipulation, file operations, network utilities, and more
- **PassingTheKnowledge--Batchography** — Educational batch scripting examples from "The Batchography" book
